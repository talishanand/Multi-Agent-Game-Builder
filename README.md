# 🎮 Multi-Agent Game Builder

An AI-powered multi-agent game development system built using CrewAI, Gemini, and Pygame. This project uses collaborative AI agents to transform simple game ideas into structured gameplay designs, playable Python/Pygame code, automated testing workflows, and functional 2D game prototypes.

---

## 🚀 Features

* 🤖 Multi-Agent Architecture using CrewAI
* 🎨 Game Designer Agent for gameplay planning
* 💻 Developer Agent for Python/Pygame code generation
* 🧪 QA Agent for testing and reviewing game outputs
* ⚡ Automated AI-driven game development workflow
* 🎮 Generates playable 2D game prototypes
* 🔄 Collaborative task execution between AI agents

---

## ⚙️ How It Works

1. User provides a game idea or concept.
2. The Game Designer Agent creates gameplay mechanics and structure.
3. The Developer Agent generates Python/Pygame code.
4. The QA Agent reviews and validates the generated game.
5. Final output is a playable 2D game prototype.

